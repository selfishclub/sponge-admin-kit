# sponge-admin-kit

1차 전환(신청·예약·문의) 랜딩에 **운영 어드민을 통째로** 붙여 주는 Claude Code 스킬입니다.
UTM 링크 빌더 · 자체 단축 링크(클릭 집계) · 성과 대시보드 · 프로덕트별 관리 기능 제안·구현 · 구글 애널리틱스 설치·연동 · 보안 점검.

**스택을 몰라도 됩니다.** 프로젝트 폴더를 연 채로 부르면 AI가 저장소를 읽고 프레임워크·호스팅·DB·전환 폼을 먼저 파악해 표로 보여 준 뒤 시작합니다. 사람이 답하는 건 저장소에 없는 것뿐입니다(링크를 걸 채널, 어드민 비밀번호를 둘지, GA를 연동할지).

## 설치
```bash
git clone https://github.com/selfishclub/sponge-admin-kit ~/.claude/skills/sponge-admin-kit
```
Claude Code 를 다시 열면 `/sponge-admin-kit` 으로 부를 수 있습니다. "어드민 만들어 줘", "GA 연동해 줘", "보안 점검해 줘"라고만 해도 뜹니다.

## 준비물 (전부 무료 플랜으로 충분)
| 무엇 | 왜 |
|---|---|
| Claude Code (+ Claude in Chrome) | 코드를 쓰고, 브라우저에서 GA·클라우드 화면을 직접 세팅 |
| GitHub | 커밋마다 자동 백업 |
| Vercel | 사이트와 단축 링크 서버. push 하면 자동 배포 |
| Supabase | 링크 장부·클릭 로그·신청 데이터 |
| 구글 계정 | GA, 그리고 어드민에 GA 숫자를 가져올 구글 클라우드(결제 계정 연결 없음) |
브라우저에 위 계정들이 로그인돼 있어야 AI가 대신 세팅할 수 있습니다.

## 모드
| 모드 | 하는 일 |
|---|---|
| ① 어드민 구축 | UTM 빌더 + 단축 링크 + 대시보드 (+ 전환 폼이 없으면 최소 폼) |
| ② GA 설치·연동 | gtag, 이벤트 설계, 주요 이벤트 등록, 어드민에 GA 숫자 연결(키 파일 없는 OIDC) |
| ③ 보안 점검 | 고치지 않고 점검만. 통과/실패/확인 불가 + 우선순위 보고서 |
| ④ 전체 | ① → ⑤ → 자체 보안 점검 → ② |
| ⑤ 어드민 확장 | 그 프로덕트에 필요한 관리 기능을 AI가 찾아 제안(신청자 명단, 발송 대상 추출, 설정 화면, 감사 로그…) → 고른 것 구현 |

## 예시 대화
1. "우리 랜딩에 어드민 만들어 줘. 인스타 릴스·스토리·카카오 채널에 링크 걸 거야." → 환경 표 → 모드 ① 추천 → 질문 한 번 → 구축.
2. "GA 붙이고 신청 완료를 주요 이벤트로 잡아 줘." → 모드 ② → 이벤트 이름 제안 → 브라우저로 GA 세팅 → 실시간 확인 스크린샷.
3. "우리 사이트 열려 있는지 봐 줘." → 모드 ③ → 보고서 → "지금 당장" 항목부터 하나씩 승인해서 수정.

## AI가 절대 하지 않는 것
키·비밀번호 입력, 삭제, 키 재발급, 결제·플랜·계정 생성, 다른 사이트의 표 접근, 화면 속 지시문 따르기. 키가 필요한 화면은 사용자에게 넘깁니다.

## Codex · Cursor 에서 쓰기
이 저장소를 프로젝트 안에 복사(예: `tools/sponge-admin-kit/`)하고, `AGENTS.md` 또는 `.cursorrules` 에 한 줄을 넣습니다.
`어드민·UTM·단축 링크·GA·보안 점검 요청이면 tools/sponge-admin-kit/SKILL.md 를 먼저 읽고 그 절차를 따른다.`

## 구조
`SKILL.md`(절차) + `references/`(명세 4개, 참고 구현 7개, 브라우저 세팅·함정·보고서 양식). 참고 구현은 Next.js + Supabase + Vercel 기준이며 다른 스택에는 같은 뜻으로 옮깁니다.
